# Todo List simple

Proyecto pequeño: lista de tareas con HTML, CSS y JavaScript.

Cómo usar

1. Abrir el archivo `index.html` en un navegador (doble clic o `start index.html` en PowerShell).
2. Escribir una tarea y pulsar `Añadir` o Enter.
3. Marcar la casilla para completar, o pulsar `Eliminar` para borrar.
4. Las tareas se guardan en `localStorage` del navegador.

Archivos

- `index.html` — interfaz principal.
- `styles.css` — estilos responsivos y accesibles.
- `app.js` — lógica: añadir, eliminar, marcar y persistir.
